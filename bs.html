Bootstrap — Component-Based Framework

Bootstrap menyediakan komponen siap pakai. Developer cukup gunakan class component yang sudah jadi tanpa perlu mendefinisikan style satu per satu.

Penjelasan Class:
  • btn → Class dasar tombol: padding default, border, cursor pointer, font styling, display inline-block
  • btn-primary → Variant warna bawaan Bootstrap: background biru, teks putih, efek hover, border color
