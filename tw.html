TailwindCSS — Utility-First Framework

Tailwind menyediakan utility kecil, bukan komponen jadi. Developer membangun komponen sendiri dari utility.

Penjelasan Class:
  • px-4 → Padding horizontal (kiri & kanan). p = padding, x = sumbu horizontal, 4 = skala spacing (1rem / 16px)
  • py-2 → Padding vertikal (atas & bawah). 2 = skala spacing lebih kecil (0.5rem / 8px)
  • bg-blue-600 → Background warna biru. 600 = tingkat intensitas warna
  • text-white → Warna teks putih
  • rounded-lg → Border radius ukuran besar, membuat sudut membulat
